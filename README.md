# إنجاز

برنامج عربي لإدارة أعمال المدرسة ومتابعتها: الخطة التشغيلية، وخطة تحسين الأداء المدرسي،
والإشراف التربوي المقيم، والانضباط المدرسي، والتعاميم، ووحدة الوعي الفكري، والأمن والسلامة،
والأندية، وإنجازات المعلمين، والمهام اليومية، والبرامج القريبة والمنتهية، ولوحة المؤشرات،
وسجل العمليات.

## محتوى المستودع

- `claude-version/` النسخة الحالية التي تعمل داخل Claude.
- (قريباً) `web/` النسخة المستقلة على Firebase، وتُنشر تلقائياً على Cloudflare Pages.

## التطوير

يتم التطوير والصيانة عبر Claude من خلال هذا المستودع. يشرح ملف `CLAUDE.md` هيكل البرنامج.
